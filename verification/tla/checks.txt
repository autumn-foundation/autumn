# The TLC checks that scripts/verify-tla.sh runs. One check per line:
#
#   <expect>  <spec>  <variant>  <property> [<property> ...]
#
# holds     TLC checks every reachable state, and every property holds.
#           The run also fails when it visits MAX_STATES or more states.
# violates  TLC must find a counterexample for each property (one run each).
#           A seeded bug that gives no counterexample fails the check.
# reaches   Each property must be true in some reachable state (one run
#           each). A correct model that never reaches it is vacuous.
#
# verification/models/tests/tla_checks.rs fails when a seeded bug of a
# Stateright twin has no line here.
