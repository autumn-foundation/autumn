🎯 What: Fixed a command injection vulnerability in `autumn-cli` where the `EDITOR` or `VISUAL` environment variable was incorrectly parsed by blindly splitting on whitespace, which allowed execution of unintended binaries if a path contained spaces.
⚠️ Risk: If a user's `EDITOR` or `VISUAL` variable was manipulated or contained a path with spaces (e.g. `C:\Program Files\editor`), the naive whitespace splitting caused `Command::new` to execute an attacker-controlled binary (e.g. `C:\Program.exe` or `C:\Program`). This allowed execution of arbitrary binaries with arbitrary arguments.
🛡️ Solution: Migrated from `split_whitespace()` to the `shlex` crate. `shlex::split` safely handles quoted strings according to POSIX shell rules, ensuring the editor binary and its arguments are correctly separated, thus preventing command execution via improperly split environment variables.
