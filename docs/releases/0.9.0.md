# Autumn 0.9.0 — *Stay up under load*

A narrative tour of the release. The complete record is the
[`0.9.0` changelog entry](../../CHANGELOG.md#090---2026-10-28); the upgrade path
from 0.8.x is the [migration guide](../migrations/0.9.0.md). This page groups
what shipped by what you are trying to do, and quotes the changelog's own
spellings rather than paraphrasing them.

0.8.0 made more of a program provable before it runs. 0.9.0 is about what
happens after: **an app that degrades instead of falling over** (load
shedding, retry budgets, deadlines, bulkheads and connection limits, most of
them on by default in `prod`), **work that happens exactly once** (an outbox and inbox,
fenced locks, scheduler ticks and job claims that survive a slow replica), and
**SQLite that scales out** to one database file per tenant or slot. Around
those, MCP and agent readiness grow from a feature into a surface.

## If you are upgrading

Most of the 48 breaks are framework structs that gained a field or enums that
gained a variant, so they only reach code that builds one with a struct literal
or matches it exhaustively. Read
[*At a glance* in the migration guide](../migrations/0.9.0.md#at-a-glance)
first. The ones an application can meet:

- **The `prod` profile sets `server.strict_config = true`.** A misspelled or
  retired key in `autumn.toml` now stops the boot instead of being ignored.
- `db` no longer compiles the Postgres client; the new default `postgres`
  feature does. A build with `default-features = false` adds `"postgres"`
  ([guide](../migrations/0.9.0.md#features-db-has-no-postgres-client-enable-postgres)).
- `RequestBuilder::retries(n)` no longer retries `POST` and `PATCH`; call
  `.retry_non_idempotent()` when the endpoint is safe to repeat.
- `autumn_http_request_duration_seconds` is now a histogram. Dashboards that
  read its `quantile` label move to `histogram_quantile`, or to the deprecated
  `autumn_http_request_duration_quantiles_seconds` for now.
- The Postgres scheduler records each tick in `autumn_scheduler_ticks`, and the
  `notifications` / `push_subscriptions` tables get a `tenant_id` column.
- `IdempotencyStore` is async and fenced by a lock owner, and
  `idempotency.in_flight_ttl_secs` defaults to `60`, not `86400`.

Behaviour changes worth a look before deploying: the `prod` profile now sheds
load, caps request heads at 64 KiB (`431`) and WebSocket messages at 1 MiB
(close code `1009`), and waits 35 s rather than 30 s on shutdown; and an app
with no `[seo]` now serves `/robots.txt` and `/sitemap.xml`
([Behavior changes](../migrations/0.9.0.md#behavior-changes)).

Run `autumn upgrade` *before* bumping the dependency: it reads the version your
`Cargo.toml` still records and lists every break above with its guide section.

## Degrade instead of falling over

- **Adaptive admission control** — `[server.admission] mode = "adaptive"`
  sizes the concurrency limit from observed latency, and routes declare what
  may be shed first: `#[get("/x", criticality = "sheddable")]`, with
  `[server.admission.partitions]` reserving capacity per class (#3068).
- **Retry budgets and full jitter** — `[http.client.retry_budget]` (on by
  default) stops a client from multiplying load on a failing host, and every
  backoff in the framework is capped full jitter (#3054).
  `[http.client.adaptive_throttle]` rejects locally with
  `ClientError::ThrottledLocally` before a request is even sent.
- **Deadlines that travel** — `Deadline::current()` and the
  `x-autumn-deadline-ms` header carry the caller's remaining budget into
  outbound calls, which fail fast with `ClientError::DeadlineExceeded` (#3058).
- **Slow-call circuit breakers** — a breaker now opens on calls that are slow,
  not only on calls that fail (#3060).
- **Per-tenant bulkheads** — `tenancy.max_concurrent_requests` and
  `tenancy.max_db_connections` keep one noisy tenant from starving the rest
  (#3072).
- **Connection and message limits** — `[server.http]` header timeouts and
  `max_connections`, and `[realtime]` message size and idle limits (#3065).

See [Timeouts and budgets](../guide/timeouts-and-budgets.md) and
[Connection limits](../guide/connection-limits.md).

## Exactly once, even when a replica is slow

- **Transactional outbox and inbox** — `Outbox::write` commits a message in the
  same transaction as the data, and `Inbox::seen` drops a redelivery (#3062).
  Framework mail, jobs and webhooks can route through it. See
  [Outbox](../guide/outbox.md).
- **Fenced leases** — `LeaseLock` hands out a `FencingToken` with each lease, so
  a holder that paused past its lease cannot write over its successor (#3053).
  See [Distributed locks](../guide/distributed-locks.md).
- **Scheduler ticks** — the Postgres scheduler claims each tick with a row in
  `autumn_scheduler_ticks`, which ends the cron double-fire a late replica
  could cause (#3052).
- **Job claims that renew** — durable workers heartbeat each claim while a job
  runs, and `#[job(timeout = "30s")]` / `jobs.default_timeout_ms` bound the
  ones that hang (#3051).
- **Idempotency in the database** — `DbIdempotencyStore`
  (`[idempotency] backend = "database"`) and an owner-fenced store contract.

## SQLite fleets

- **One database per tenant or slot** — `[database.fleet]` routes each request
  to its own SQLite file through the same `ShardedDb` / `#[repository(sharded)]`
  code a Postgres app uses, with no handler change. `DatabaseFleet` provisions,
  backs up and restores databases.
- **Replicated and owned** — each fleet database replicates its WAL, a missing
  file can be rebuilt from it, and slot ownership is fenced by epoch so a stale
  node answers `421` (#3233). A sweeper finishes outbox and commit-hook work for
  databases that are closed (#3234).
- **`autumn fleet list | migrate | backup | delete | restore`** (#3232).

See [SQLite fleet](../guide/sqlite-fleet.md).

## Agents and MCP

- **MCP Tasks** — `#[api_doc(mcp, task)]` turns a long-running tool into a task
  the client polls and can cancel.
- **Progressive discovery** — `AppBuilder::mcp_catalog(McpCatalog::Progressive)`
  exposes a small core set plus `search_tools` / `call_tool`, so a large app
  does not flood the client's context. The endpoint speaks the `2026-07-28`
  protocol revision alongside the previous one.
- **Repository grants** — `#[repository(.., mcp, grant = X)]` governs the
  generated MCP tools, and a grant's `rate` is enforced (#2451).
- **WebMCP** — the `webmcp` feature hands routes tagged `#[api_doc(webmcp)]`
  to the agent in the user's own browser. `AppBuilder::mount_webmcp()` serves
  the tool list, and `js/autumn-webmcp.js` registers each one with
  `document.modelContext.registerTool()`. A call is a same-origin `fetch` that
  carries the user's session and CSRF token, a `DELETE` or non-reversible
  tool asks the user first, and `webmcp::form_tool` makes a `<form>` a tool
  (#2619). See [WebMCP](../guide/webmcp.md).
- **Agent readiness on by default** — `Accept: text/markdown` returns Markdown,
  and the app serves a generated `/llms.txt`, `/robots.txt` and the
  `/.well-known` agent catalogs. See [AEO](../guide/aeo.md).

See [MCP](../guide/mcp.md).

## Operating it

- **SLOs as code** — `[[slo]]` tables and `autumn slo generate` emit Prometheus
  rules, Grafana dashboards and canary analysis for Argo or Flagger (#3069).
  See [SLOs](../guide/slo.md).
- **Kubernetes** — `autumn release init --target kubernetes` writes a Helm
  chart and a Kustomize base. See [Kubernetes](../guide/kubernetes.md).
- **Bake and roll back** — `autumn deploy up` watches a new release for
  `[deploy.bake]` and rolls it back on failure.
- **Probes that tell the truth** — `/ready` pings the primary over a dedicated
  connection, and health results are cached (`health.cache_ttl_ms`) (#3059).
- **Fault injection for staging** — `[fault_injection]` (#3071). See
  [Fault injection](../guide/fault-injection.md).
- **Cost signals** — `[cost] enabled` adds `Server-Timing`, `/actuator/cost`
  and `#[job(deferrable)]` work that waits out a busy period (#1720). See
  [Cost](../guide/cost.md).

## Edge, schema and the dev loop

- **Run the edge anywhere** — `autumn edge serve` runs an edge node locally, a
  web-standard JS host runs the capsule on Workers, Deno, Bun or Node, and
  `autumn edge bundle --target cloudflare` packages it (#1790). See
  [Edge](../guide/edge.md).
- **Schema renames and live diffs** — `#[renamed_from("old")]`,
  `#[references(on_delete = …)]`, and `autumn schema diff --dev-url` against a
  live development database (#1975). See
  [Declarative schema](../guide/declarative-schema.md).
- **A console REPL** — `autumn console --repl`, a Rhai prompt over the app
  (#2148). See [Console](../guide/console.md).
- **Forms** — `FieldOptions` and a `*_with` variant of each helper (#3395), and
  repeated keys decode into a `Vec` (#3394). See [Forms](../guide/forms.md).
- **Portable data** — `autumn data capsule export | import | verify` hands a
  user their data as a verifiable capsule (#1811). See
  [Data capsules](../guide/data-capsules.md).
- **Multi-replica simulation** — `Sim::mount_replica` runs several replicas
  against one simulated world, each with its own clock (#3067). See
  [Simulation testing](../guide/simulation-testing.md).

## Plugins

- **Hot mount** — `PluginMounts` mounts and unmounts a sandboxed plugin on a
  running app (#2433).
- **Plugin assets** — `AppBuilder::plugin_assets` serves a plugin's
  JavaScript, CSS and fonts at content-hashed URLs with SRI. See
  [Plugin Assets](../guide/plugin-assets.md).

## Production defaults, by default

The theme under all of this is that the `prod` profile now ships the posture a
production service ends up hand-tuning: strict config, load shedding, request
deadlines, retry budgets, connection limits and statement timeouts. Every one of
them can be loosened in `autumn.toml`, and each is listed in the migration
guide's [Configuration changes](../migrations/0.9.0.md#configuration-changes),
but none of them has to be discovered during an incident first.
