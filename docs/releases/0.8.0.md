# Autumn 0.8.0 — *Prove it, then run it anywhere*

A narrative tour of the release. The complete record is the
[`0.8.0` changelog entry](../../CHANGELOG.md#080---2026-10-01); the upgrade path
from 0.7.x is the [migration guide](../migrations/0.8.0.md). This page groups
what shipped by what you are trying to do, and quotes the changelog's own
spellings rather than paraphrasing them.

0.7.0 was about shipping and proving a deploy. 0.8.0 pushes the same idea out in
three directions: **more of a program is checked before it runs** (compile-time
contracts, a build-time query budget, a simulated network), **SQLite becomes a
full backend** rather than a development convenience, and **the things a
production app has to hold — money, personal data, tenants, certificates — become
framework primitives** instead of code every app rewrites.

## If you are upgrading

Almost all of the breaks are at seams an application rarely crosses, and most of
them turn a wrong-but-compiling program into a compile error. Read
[*At a glance* in the migration guide](../migrations/0.8.0.md#at-a-glance) first.
The ones an app can meet:

- `autumn-macros` is now four crates; an app that depends on `autumn-web` is
  unaffected, a direct dependant loses `autumn_macros::{model, repository,
  service}`.
- `http_client::ClientError` is `#[non_exhaustive]` — a `match` needs a `_` arm.
- Built-in widget CSS classes are `autumn-`-prefixed.
- `#[commentable(by = <AuthorModel>)]` checks `author_name` against the author
  struct at compile time.
- `validator` moves to `0.21`; an app's `#[derive(Validate)]` pin must follow.
- `consent::inject_consent_banner` takes its CSRF cookie name as
  `Option<&str>`. **Every app generated by `autumn new` calls it** from
  `src/main.rs`, so wrap that argument in `Some(..)`
  ([guide](../migrations/0.8.0.md#consent-inject_consent_banner-takes-csrf_cookie_name-optionstr)).

One behaviour change is worth a look before deploying: `asset_url("js/htmx.min.js")`
and the other framework scripts now resolve to content-hashed URLs, and the
admin plugin's `admin.js` moved under `/static/_plugins/autumn-admin/`
([Behavior changes](../migrations/0.8.0.md#assets-framework-scripts-are-served-at-content-hashed-urls)).

Run `autumn upgrade` *before* bumping the dependency: it names every registered
0.8.0 break and links the guide section for it.

## Prove more before it runs

- **Simulation testing grows a network and a shuffler.** `sim::SimNet` simulates
  outbound traffic, `Sim::interleave` polls futures in an explored order,
  `sim::crash_at` drops an operation at any await, `#[scheduled]` tasks run
  under `Sim`, and `Sim::try_run_to_idle` returns a `SimStall` instead of
  hanging. A `sim_ops` cargo-fuzz target drives the same operations, and an
  opt-in liveness watchdog guards `#[sim_test]`.
- **`#[query_budget(N)]`** is a compile-time, per-route database query budget.
- **Cache coherence is proven at build time:** the build fails when a write can
  leave a cache stale.
- **Build-checked typed contracts between two Autumn services** (#1755).
- **A proven capacity contract that travels with the build** (#1733), and
  **security posture diffs** that gate pull requests.
- **A queryable architecture graph** derived from the app's own macros, and a
  **build-time authority envelope** for agent-operable handlers (#1691).
- **Stricter macros.** Aliased or ambiguous `#[authorize]` shapes, `#[feature_flag]`
  on `static_get`, an unsound `#[lifecycle]` graph, and `owner = column` beside
  `api = "..."` without a `policy` no longer compile.

## SQLite as a first-class backend

- **Durable background jobs and a single-host scheduler** on SQLite.
- **Continuous SQLite replication with point-in-time restore** (#1628), plus
  `autumn db backup` / restore and deploy persistence (#1909).
- **DB-backed sessions, `autumn generate teams`, `Uuid`/`decimal{p,s}`/`enum{…}`
  model fields and the admin plugin** now run on SQLite.
- **`Db::tx_immediate`** for explicit immediate-mode transactions.

## Primitives a production app keeps rewriting

- **Money** — typed `Money<C>` with an enforced double-entry ledger.
  `Money<Usd>` plus `Money<Eur>` does not compile.
- **Ledgered entities** — time-travelable and tamper-evident by construction.
- **Personal data that cannot reach a JSON response by accident** (#1654), and
  **`#[confidential]`** fields sealed under a key the server does not hold.
- **Collaborative fields** — make a record collaboratively editable.
- **`autumn-billing`** — first-party subscription billing (#1190).
- **Web Push** — notifications that reach a device with the tab closed.
- **Calendar-aware SLA obligations** (#1826) and a **CSV import route** from
  `autumn generate scaffold --import`.
- **Admin user impersonation** with an audit trail and a revert banner (#1394).

## Starters and examples

- **`autumn new <name> --starter cms`** scaffolds a complete content management
  system — posts, pages and custom post types, taxonomies, scheduled
  publishing, revisions, a media library, moderated comments, roles, menus,
  themes, feeds and a REST API — joining `saas` as the second built-in starter.
  The rendered starter is committed as `examples/cms/`.
- **`examples/react-graphql`** — a TypeScript React single-page app on an
  Autumn backend that serves GraphQL through a plugin.
- **`autumn openapi export`** writes the app's OpenAPI 3.1 document without
  booting it — the same document `/openapi.json` serves.

## TLS, certificates and tenants

- **Mutual TLS** on the native listener (#1640).
- **Wildcard certificates via DNS-01** for tenant subdomains (#1620), ACME
  against a private CA with an end-to-end proof, and tenants that connect their
  own domains.
- **Direct HTTPS is proven end to end**, including in the release-image boot gate.

## Operating it

- **Shadow (differential) deploys** mirror live traffic to a candidate build.
- **Zero-downtime in-place upgrades** with a compile-checked state migration.
- **`autumn db scrub`** turns a production copy into an anonymized one, with
  post-condition checks and a dry-run that sizes every target first.
- **Native Windows daemon lifecycle and Windows Service registration** (#1639),
  backed by a published Windows support policy and a `windows-latest` journey.
- **SBOMs and signed provenance** for framework and app releases (#1615).
- **One retention policy for every table Autumn creates** (#1605) — see
  [Data retention](../guide/data-retention.md).

## Plugins

- **A curated plugin index** and one-command `autumn plugin add` / `list` /
  `remove` (#1625, #1631).
- **Capability-sandboxed plugins** — install an unaudited plugin without handing
  it the process.
- **A versioned stability contract for the plugin API** (#1601).
- **`AppBuilder::plugin_migrations(name, migrations)`** for named plugin
  migrations.
- **`AppBuilder::plugin_assets`** — a plugin ships its JavaScript, CSS and fonts
  as a `PluginAssets` bundle, served at content-hashed, `immutable` URLs with
  SRI hashes, no build step required. See [Plugin Assets](../guide/plugin-assets.md).

## The docs are gated now

The guide has an index (`docs/guide/index.md`) and a gate that keeps it
complete. Links, CLI commands, `AUTUMN_*` keys, `autumn.toml` keys, Rust
symbols, actuator paths and release-line pins in the docs are each checked by
their own script, and the getting-started snippets are compiled in CI.
