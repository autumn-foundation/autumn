# Autumn 0.10.0 — *Pay for what you use, run it in more shapes*

A narrative tour of the release. The complete record is the
[`0.10.0` changelog entry](../../CHANGELOG.md#0100---2026-11-04); the upgrade
path from 0.9.x is the [migration guide](../migrations/0.10.0.md). This page
groups what shipped by what you are trying to do, and quotes the changelog's
own spellings rather than paraphrasing them.

0.9.0 kept an app standing under load. 0.10.0 is about its shape: **an app
that compiles only what it uses** (16 modules, four widget families, `jwt` and
`push` are now features), **one codebase that runs as several kinds of
process** (named role presets, a capability set per process, and route groups
mounted per role), and **a widget set that is a design system** (design
tokens v2 with dark mode, a keyboard core, popovers, drawers, tooltips,
toasts, a tags mode, and widget packs for plugins). Around those, the SQLite
fleet learns to delete, check and query its replicas, and the toolchain moves
to Rust 1.97.0.

## If you are upgrading

The release has 17 breaking changes. Read
[*At a glance* in the migration guide](../migrations/0.10.0.md#at-a-glance)
first. The ones an application can meet:

- **Rust 1.97.0 is the new MSRV** (was 1.88.0). Move `rust-toolchain.toml`,
  `clippy.toml`, CI and the `Dockerfile` together
  ([guide](../migrations/0.10.0.md#toolchain-rust-1970-or-newer)).
- **`reqwest` 0.13.** An app that passes `reqwest` types to Autumn moves too,
  and an app's own client needs a TLS feature such as `rustls`, because
  `autumn-web` now turns on `rustls-no-provider`
  ([guide](../migrations/0.10.0.md#http-client-reqwest-013)).
- **A `default-features = false` build** names the features it uses: 16
  modules (`feature-flags`, `money`, `ledger`, `wizard`, …), four widget
  families (`widgets-search`, `widgets-social`, `widgets-workflow`,
  `widgets-charts`), `jwt` and `push`. A default build does not change.
- **An unknown `AUTUMN_ROLE` stops the boot.** Before, a typo such as
  `AUTUMN_ROLE=workers` booted the app as `combined`, with user routes, every
  job queue and the cron scheduler. `state.role()` now returns a `&Role`; call
  `.base()` for the `ProcessRole`.
- **Widget class names.** `alert alert-error` is now
  `autumn-alert autumn-alert--error`, `badge--success` is
  `autumn-badge--success`, and `wizard-*` is `autumn-wizard-*`. A `NavMenu`
  is a popover menu, closed with JS off.
- **Struct literals** of `Route`, `AutumnConfig`, `DatabaseFleetConfig` and
  `AutocompleteConfig` need the new fields, and a custom `JobTrackingStore`
  implements `update_record` in place of five methods.

Before you deploy: run `autumn migrate`. The framework migration
`20261029183512_add_money_account_balance` adds a column the new binary reads.
Widgets now follow the OS dark mode; a page with light-only colors pins
`data-theme="light"` on `<html>`
([Behavior changes](../migrations/0.10.0.md#behavior-changes)).

Run `autumn upgrade` *before* bumping the dependency: it reads the version your
`Cargo.toml` still records and lists every break above with its guide section.

## Compile only what you use

- **Module features** — `alerts`, `custom-domains`, `data-retention`,
  `experiments`, `feature-flags`, `gdpr`, `graph`, `idempotency`,
  `job-tracking`, `ledger`, `money`, `nested-form`, `slo`, `upgrade`,
  `version-history` and `wizard` are default-on features (issue #2795, ADR
  0027). The no-DB starter no longer builds them, the `psl` crate, or the
  route graph descriptors that `#[get]` and `#[job]` emitted.
- **Widget families** — `widgets-search`, `widgets-social`,
  `widgets-workflow` and `widgets-charts` (issue #3408, ADR 0034). With no
  family, `autumn-widgets.css` is 14% smaller and `autumn-widgets.js` 13%
  smaller, and `autumn generate scaffold` adds only the families a resource
  uses.
- **`jwt` and `push`** — `jsonwebtoken` and `p256` are optional (ADR 0035).
  An app that leaves out `jwt` (and `oauth2`) no longer compiles `rsa` 0.9
  (RUSTSEC-2023-0071) or `crypto-bigint` 0.5 (RUSTSEC-2026-0387), and can drop
  both waivers from its `deny.toml`.
- **Diesel table width** — `autumn schema width` reports every `table!` and
  `#[model]` over 32 columns, and `autumn build` warns on the same. Measured on
  one crate: 1.16 GB / 1m18s at 32 columns, 2.92 GB / 2m04s at 64, 9.95 GB /
  8m16s at 128. See [Table width](../guide/table-width.md).

## One codebase, several kinds of process

- **Named role presets** — `[roles.<name>]` is a built-in `base` (`combined`,
  `web` or `worker`) plus `pin`, `workers` and capability overrides, selected
  with `AUTUMN_ROLE=<name>`, `role = "<name>"` or `autumn serve --role <name>`
  (issue #3543, ADR 0035). `state.role().name()` gives the name, and a preset
  labels the framework metrics.
- **Capabilities** — each process resolves one `RoleCapabilities` set at boot,
  and each background subsystem reads its own field: `job_workers`,
  `scheduler`, `outbox_relay`, `commit_hooks`, `fleet_relay`,
  `restore_check` and `retention`. Ask with
  `state.capabilities().runs(Capability::Scheduler)` (issue #3542, ADR 0033).
- **Route groups** — `#[get("/x", group = "marketing")]`, `Route::in_group`,
  `AppBuilder::routes_in(..)` or `Plugin::route_group()`, and
  `[roles.<name>] mount = ["marketing"]` serves only those groups (issue
  #3544, ADR 0036). The graph, `/openapi.json`, pre-rendered pages and the
  sitemap follow the mount, and `autumn doctor` warns on a group no role
  mounts.
- **Table ownership** — `autumn graph check-boundaries` fails when a route,
  job or repository in one boundary reaches a table another boundary owns
  (issue #3549). See [Table ownership](../guide/table-ownership.md).

See [Web and worker process roles](../guide/jobs.md#web-and-worker-process-roles).

## A widget set that is a design system

- **Design tokens v2** — every color token is `light-dark(<light>, <dark>)`,
  so the widgets, the admin plugin, the actuator dashboard and the error pages
  follow the OS dark mode with no JS. `data-theme` and `data-density` override
  it on any element, and `theme_toggle` is a System / Light / Dark switch that
  works without JS (issue #3396). See
  [Widget styling](../guide/widget-styling.md).
- **A keyboard core** — `autumn-widgets.js` gives roving tabindex,
  `aria-activedescendant`, Home/End, typeahead and dismiss through
  `data-autumn-roving`, `data-autumn-activedescendant` and
  `data-autumn-dismiss` (issue #3397). Tabs, autocomplete and the nav menu use
  it. See [Keyboard](../guide/keyboard.md).
- **New widgets** — `popover` and `dropdown_menu` on native `popover` and CSS
  anchor positioning (#3402), `drawer` and dialog sizes (#3403), `tooltip`
  (#3404), `accordion` and `collapsible` on `<details>` (#3401), and the small
  display set: `button`, `button_group`, `spinner`, `skeleton`, `progress`,
  `meter`, `kbd` and `empty_state` (#3406). See
  [Popover and menu](../guide/popover-and-menu.md) and
  [Display widgets](../guide/display-widgets.md).
- **Toasts** — a close button, a pause on hover or focus (WCAG 2.2.1), and the
  top layer, so a modal does not cover them (#3399).
- **Forms** — native input helpers (`switch_input`, `range_input`,
  `radio_group`, `segmented_control`, …, #3405), `<optgroup>` and
  `multiple` selects (#3409), a tags mode for `autocomplete_input` (#3410), a
  `direct_upload_input` that `autumn-widgets.js` drives with a progress bar
  (#3411), and `otp_input` with password reveal and strength hints, which
  `autumn generate auth` now uses (#3412). See [Forms](../guide/forms.md).
- **Widget packs** — a plugin crate ships widgets as a `WidgetPack`: a name,
  stories and a `PluginAssets` bundle, installed with
  `AppBuilder::widget_pack` and checked by `plugin_conformance::widgets`
  (#3400). See [Widget packs](../guide/widget-packs.md).

## SQLite fleets, continued

- **Deletes that reach the replica** — with `[replication]` on, a fleet delete
  purges the database's replica too, behind a tombstone row on the control
  database. `database.fleet.replica_retention_after_delete` keeps it for an
  undo window (issue #3235).
- **Restore checks** — each worker-role process restores
  `database.fleet.restore_check_sample` random databases on a schedule and
  checks `PRAGMA integrity_check` and the identity row.
- **Query the lake** — `fleet.lake()?.materialize().await?.query(sql)` and
  `autumn fleet lake <sql>` run one `SELECT` across every tenant's replica on
  a host with no volume (issue #3236, ADR 0032).
- **Throughput** — `database.fleet.replication_workers` (default `4`) ships
  fleet databases in parallel; one thread used to let replication lag pass
  `rpo_secs` with 150 to 230 databases per host. `DatabaseFleet::import` and
  `autumn fleet import` bring a database file in, and
  `AppBuilder::migrations_for` scopes a migration set to the control database
  or the shards.

See [SQLite fleet](../guide/sqlite-fleet.md).

## Data and correctness

- **A stored money balance** — each account row stores `balance_minor`, kept
  by a trigger, so `ledger::post` no longer reads the posting history: on the
  `ledger_post` bench, 900 payouts went from 47.5G to 4.1G instructions.
  `ledger::balance_drift` reports a mismatch (issue #3339, ADR 0028). See
  [Money](../guide/money.md#the-stored-balance).
- **Batched ledgered writes** — the bulk repository writes on a
  `ledgered = true` repository send 5 statements per chunk of 1,000 rows, not
  5 per row (issue #3345, ADR 0029).
- **Any primary key** — `#[model]` accepts a key column that is not `id`, and
  `#[belongs_to(Post, references = "post_uuid")]` names a parent's key once
  (issue #3033).
- **Billing redeliveries** — `EventClaim::Duplicate` is split into `Applied`
  and `InFlight`, so a redelivery that meets an unfinished claim gets `503`
  and is retried rather than lost (issue #3097).
- **`autumn migrate check`** reads quoted identifiers, dollar quotes and
  comments with the lexer rules of the app's backend (#3437, #3518).

## Faster requests

A request through the default ingress stack allocates 98 heap blocks and
15,666 bytes, down from 133 blocks and 28,270 bytes (issue #2830). The log
context, trusted-proxy, idempotency-replay and transaction-timeout layers no
longer box a future, and the session layer boxes only to load or save a
session.

## Toolchain and dependencies

Rust 1.97.0 is the MSRV. Every dependency that can move is raised:
`reqwest` 0.13, `webauthn-rs` 0.6, `p256` 0.14, `sha2` 0.11, `hmac` 0.13,
`aes-gcm` 0.11, `serde-saphyr` 2 and more. `webauthn-rs` 0.6 uses pure-Rust
crypto, so a new passkey app no longer needs OpenSSL, and `autumn doctor` no
longer asks Windows users for vcpkg. See
[Upstream dependency updates](../migrations/0.10.0.md#upstream-dependency-updates).
